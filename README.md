## Overview

A small, personal web page that presents a love letter to my girlfriend, celebrating her hard work and dedication. It is built with plain HTML, CSS, and JavaScript, so it opens in any browser and can be shared as a link.

## Features

- **Animated letter presentation** written in vanilla JavaScript.
- **Custom styling** and imagery.
- **Zero dependencies:** no build step required.

## Tech Stack

| Area | Technology |
| --- | --- |
| Markup and styling | HTML5, CSS3 |
| Logic | Vanilla JavaScript |
